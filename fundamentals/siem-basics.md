# SIEM Basics

## What this topic is about
SIEM is a cybersecurity tool used to collect, normalize, and analyze logs and events from multiple sources such as servers, applications, and security devices.

It provides a centralized view of activity across an organization and helps security analysts identify suspicious activity and generate alerts based on collected events.

## Why this matters in cybersecurity
SIEM is important because modern organizations generate a large amount of security-related data. Without a centralized system, it would be difficult and time-consuming to analyze events across different systems.

By collecting and correlating logs in one place, SIEM supports incident detection and helps analysts better understand what is happening in the environment.

## Key concepts (in my own words)
- Logs are records of events generated by systems and applications.
- SIEM collects logs and events from many different sources into one platform.
- Normalization helps convert different log formats into a consistent structure.
- Correlation helps identify suspicious patterns across multiple events.
- Alerts notify analysts when potentially suspicious activity is detected.

## Security perspective
From a defensive and investigative perspective, SIEM helps analysts review activity, identify timelines of events, and support security investigations by providing structured and searchable data.
